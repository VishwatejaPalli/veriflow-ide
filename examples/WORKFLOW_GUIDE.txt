┌──────────────────────────────────────────────────────────────────────┐
│                      EXAMPLE USAGE WORKFLOW                          │
└──────────────────────────────────────────────────────────────────────┘

    Step 1: Open IDE
    $ python main.py

    Step 2: Use Menu System
    Tools → Simulation & Verification → Compile with Icarus Verilog...
    
    Step 3: Configure in Dialog
    ┌─────────────────────────────┐
    │ Add: alu.sv, alu_tb.sv      │
    │ Output: alu_tb.vvp          │
    │ Standard: SystemVerilog     │
    │ Preview: iverilog -g2012... │
    └─────────────────────────────┘
    
    Step 4: Execute
    Click OK → Check Console tab for output
    
    Step 5: View Results
    - Console: Compilation messages
    - Diagnostics: Errors with line numbers
    - History: Re-run with one click
